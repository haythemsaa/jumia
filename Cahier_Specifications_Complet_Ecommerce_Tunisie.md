| **Faible adoption clients** | Moyenne | Critique | - Marketing agressif pré-lancement (2 mois avant)<br>- Promo lancement: -20% première commande<br>- Parrainage généreux (5 TND filleul + parrain)<br>- UX optimisée (tests utilisateurs avant lancement)<br>- Programme influenceurs (50 micro-influenceurs) |
| **Problèmes paiement** | Faible | Élevé | - Tests exhaustifs gateway (tous scénarios)<br>- Multi-gateway (backup si principal down)<br>- Paiement cash disponible (fallback)<br>- Monitoring temps réel transactions<br>- Support paiement dédié 24/7 |
| **Faille sécurité** | Faible | Critique | - Audit sécurité externe (penetration testing)<br>- Code review systématique (pair programming)<br>- Mises à jour automatiques dépendances<br>- Bug bounty program (récompenses hackers éthiques)<br>- Assurance cyber-risques (20K/an)<br>- Plan de réponse incident documenté |
| **Concurrence agressive** | Élevée | Élevé | - Différenciation: Service client premium<br>- Focus vendeurs locaux (made in Tunisia)<br>- Livraison ultra-rapide (24h Grand Tunis)<br>- Programme fidélité généreux<br>- Innovation continue (IA, features exclusives)<br>- Time-to-market rapide (lancement avant concurrents) |
| **Problèmes logistique** | Moyenne | Élevé | - Partenariats multiples transporteurs (redondance)<br>- Livraison propre en backup (Phase 2)<br>- Assurance colis (couverture pertes/dommages)<br>- Tracking temps réel transparent<br>- Gestion proactive incidents (équipe dédiée)<br>- SLA stricts transporteurs (pénalités retards) |
| **Conformité légale** | Faible | Élevé | - Conseil juridique dès départ (avocat spécialisé e-commerce)<br>- Veille réglementaire continue<br>- Mise à jour CGV/CGU régulière<br>- Formation équipe conformité RGPD/INPDP<br>- Documentation exhaustive (audit trails)<br>- Déclaration INPDP avant lancement |

### 14.1 Glossaire Technique

| Terme | Définition |
|-------|------------|
| **API (Application Programming Interface)** | Interface permettant la communication entre différents logiciels |
| **CDN (Content Delivery Network)** | Réseau de serveurs distribués pour accélérer la livraison de contenu |
| **CLV (Customer Lifetime Value)** | Valeur totale qu'un client génère sur toute sa durée de vie |
| **COD (Cash On Delivery)** | Paiement à la livraison (espèces) |
| **CSP (Content Security Policy)** | Politique de sécurité du contenu web |
| **CSRF (Cross-Site Request Forgery)** | Attaque exploitant la confiance d'un site envers l'utilisateur |
| **ETA (Estimated Time of Arrival)** | Temps d'arrivée estimé |
| **GMV (Gross Merchandise Value)** | Valeur brute des marchandises vendues (avant commissions) |
| **JWT (JSON Web Token)** | Standard pour créer des tokens d'accès sécurisés |
| **KPI (Key Performance Indicator)** | Indicateur clé de performance |
| **LCP (Largest Contentful Paint)** | Métrique de performance web (temps affichage élément principal) |
| **ML (Machine Learning)** | Apprentissage automatique (intelligence artificielle) |
| **MVP (Minimum Viable Product)** | Produit minimum viable pour lancement |
| **NPS (Net Promoter Score)** | Indicateur de satisfaction client (-100 à +100) |
| **ORM (Object-Relational Mapping)** | Technique de programmation pour mapper objets et bases de données |
| **OTP (One-Time Password)** | Mot de passe à usage unique |
| **PCI-DSS (Payment Card Industry Data Security Standard)** | Norme de sécurité pour paiements par carte |
| **PWA (Progressive Web App)** | Application web avec fonctionnalités d'app native |
| **RGPD (Règlement Général sur la Protection des Données)** | Loi européenne protection données personnelles |
| **RMA (Return Merchandise Authorization)** | Autorisation de retour marchandise |
